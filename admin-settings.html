Administração do Atlas TI

Entre com sua conta corporativa para configurar os diretórios LDAP e o administrador inicial.

Configurações de autenticação

Acesso administrativo

Configure até dois servidores LDAPS. O sistema tenta o servidor secundário quando o primário estiver indisponível. Alterações são gravadas no banco e passam a valer nos próximos logins.

Use {0} para o usuário informado. Ex.: {0} ou {0}@empresa.local.
Normalmente sAMAccountName no Active Directory.
Raiz da pesquisa de usuários e grupos no Active Directory. Exemplo: DC=gacc,DC=local.
Conta técnica de leitura do AD. Pode usar UPN ou DN; não precisa ser administradora do domínio.
A senha é criptografada pela API antes de ser salva.
Carregue os grupos do diretório e associe cada DN ao papel desejado. A associação direta é sincronizada no login; a saída do grupo remove o papel JIT no próximo login.
A conta escolhida precisa ter entrado no sistema ao menos uma vez. Ao salvar, a permissão Administrador será transferida para ela.

Use uma conta técnica dedicada, sem privilégios administrativos, com leitura/pesquisa dos usuários e grupos na Base DN. O AD normalmente já permite leitura ao usuário autenticado; se houver ACLs restritivas, conceda leitura de sAMAccountName, distinguishedName e memberOf nas OUs relevantes. A senha é criptografada pela API antes de ser armazenada. O diretório é acessado somente por LDAPS.
